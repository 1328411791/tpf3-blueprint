# 蓝图管理界面版式调整

保持现有窗口、顶部导入按钮、搜索框、横向六分类和三列模板列表。右上角模板入口、原生建造界面、保存和放置行为保持现有实现。

参考本机 Line Roles 的原生布局与样式用法，独立实现一致的留白、内容分组和字体层级。模板名称采用原生正文样式，描述保留原生富文本缩放，模块信息与操作按钮采用注释样式；每行使用克制的深灰背景。编辑、复制、删除、分享仍在同一行最右侧，编辑和删除确认固定在同一操作列内。

- 窗口内容宽度仍为 950 UI 单位，列表高度仍为 440；滚动条始终预留宽度，避免列表长度变化造成横向跳动。游戏 `builtin.css.lua` 的纵向滚动条宽 8，本方案保守预算 16，额外留出 8 单位空隙。
- 模板行外宽 934，左右内边距各 12；内部宽度 910 = 预览 130 + 间距 16 + 文本 468 + 间距 16 + 操作 280。
- 四个操作按钮外宽各 64，间距各 8，合计 280。按钮大小明确计算原生 padding；编辑与删除确认按钮右对齐于相同边缘。
- 顶部控件间距 8、模板行间距 12。导入、模板数量和操作按钮右边缘对齐，保留右侧滚动条与行内边距。
- 仅新增限定于 `blueprint-manager-*` 类的样式文件，不注册新的导航方式，不改模板库或 v1–v4 数据兼容逻辑。

验证范围：本地 Lua 契约测试检查原生控件组合、列宽与 padding 总和、搜索与六分类组合、中英文本、编辑/复制/删除确认/分享/导入，以及既有保存和放置契约。样式文件执行并检查其规则作用范围。未操作游戏窗口；实际渲染、文字缩放和高 UI 缩放下的屏幕适配需要游戏内查看，mock 不能证明像素级视觉效果。

`content/blueprint/ui.lua` 集中负责文字、用户描述的富文本转义、按钮、卡片样式及行列间距。`row`/`column` 返回布局，`component`/`card` 返回原生组件，避免混淆原生类型要求；只有明确的卡片与操作按钮预设设置自己的颜色、字体或 padding。`manager.lua` 保留翻译、筛选、编辑状态、模板库调用和事件处理，组合 UI 层的控件。此次抽取保持生成节点结构、尺寸和交互不变。
